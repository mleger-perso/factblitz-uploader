FactBlitz Uploader

A personal command line tool that publishes finished videos to their owner's own YouTube channel.

What it does

FactBlitz Uploader is a small script run from a terminal by a single person, on their own computer. It takes a video file that is already finished, together with the title, description and tags written alongside it, and uploads that video to the YouTube channel owned by the person running it. It also sets the video thumbnail and reads back the channel name so the operator can confirm the upload is going to the intended channel.

It is not a website, not a service, and not available to anyone else. There is no sign up, no account, and no user other than the owner of the channel.

What it accesses

  • youtube.upload, to upload a video file.
  • youtube, to set the thumbnail and to read the channel title for confirmation.

Nothing else is read or written. No other person's data is touched at any point.

Privacy

The full statement is on the privacy page, and the terms of service set out how the tool may be used. In short: the authorization token stays on the operator's own machine, nothing is transmitted to any third party, and no analytics of any kind are collected.
