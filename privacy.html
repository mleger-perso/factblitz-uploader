Privacy Policy

FactBlitz Uploader. Last updated 29 September 2026.

Who this covers

FactBlitz Uploader is a personal command line tool with exactly one user: the owner of the YouTube channel it uploads to. It has no other users, collects nothing from visitors, and is not offered as a service to anyone.

What data is accessed

When the owner authorizes the tool with their own Google account, it receives permission for two YouTube Data API scopes:

  • https://www.googleapis.com/auth/youtube.upload, used only to upload a video file to the owner's channel.
  • https://www.googleapis.com/auth/youtube, used only to set that video's thumbnail and to read the channel title so the operator can confirm the correct channel before uploading.

No other Google data is requested, read, or written. No contacts, no email, no profile information, no data belonging to any other person.

What is stored, and where

The OAuth token returned by Google is written to a single file on the owner's own computer, readable only by the owner's operating system account. It never leaves that machine. It is not uploaded, backed up to any service, shared, or transmitted to any server other than Google's own API endpoints. Deleting that file immediately and completely ends the tool's access; the authorization can also be revoked at any time from the Google Account permissions page.

What is not done

  • No data is sold, rented, or shared with any third party, for any purpose.
  • No analytics, telemetry, tracking, or usage reporting of any kind.
  • No data is used to train any model.
  • No advertising, and no profiling.

Limited use

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

Changes and contact

If this policy changes, the updated text replaces this page and the date above changes with it. Questions, or a request to delete anything: open an issue on the repository.
